La tarea propone un `model_validator(mode="wrap")`. Lo probé: con `wrap` (y también con `before`) pydantic valida el JSON en modo python y `StrictModel` rechaza fechas/UUID como cadena. Reproducción mínima: `scratchpad/u00t03/m.py`:
```

before <class 'dict'> json
ERR 1 validation error for B  t  Input should be a valid datetime
```
Con `wrap`, `RecommendResult.from_wire` y `read_wire` fallaban (6 pruebas rojas, entre ellas `test_br_u0_06_from_wire_roundtrip_by_kind`). Solución con la misma semántica (opción a): se mantiene el validador `after` y la instancia lleva un atributo privado `_born_with_token` que solo se pone cuando el validador corre con el token. Anidar la instancia no exige el token; dict o JSON sin token siguen lanzando `ContractViolation`. `model_construct` sigue prohibido, así que no hay otra forma de obtener el sello.
